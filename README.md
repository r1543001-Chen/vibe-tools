# 打地鼠｜單檔離線網頁遊戲

**目前程式版本：v1.1**  
**文件更新日期：2026-10-18**  
**執行檔案：`index.html`**

## 專案簡介

這是一款專為**電腦瀏覽器與滑鼠操作**設計的打地鼠小遊戲。玩家在指定時間內點擊從九宮格洞口冒出的地鼠，每打中一隻獲得 10 分。隨著遊戲進行，地鼠會出現得更頻繁、停留得更短。

整個遊戲由**單一 HTML 檔案**組成，HTML、CSS、JavaScript、SVG 圖像及音效產生程式皆內嵌其中；不需要網路、伺服器、額外圖片、音效檔案或第三方套件。

## 快速開始

1. 取得 `whack_a_mole_v1_1.html`。
2. 在電腦上使用 Chrome、Edge 等現代瀏覽器直接開啟該檔案。
3. 選擇遊戲時間，按下「開始遊戲」。
4. 等待畫面倒數 **3、2、1**，之後用滑鼠點擊地鼠本體得分。
5. 時間結束後查看本次分數與該時間的最高分；可「再玩一次」或返回時間設定。

**注意：** 這是桌面版遊戲，沒有針對手機版面或觸控操作進行優化。

## 主要功能

- **九宮格遊戲場：** 3 × 3，共 9 個洞口。
- **自訂遊戲時間：** 10～180 秒，預設 30 秒；可輸入秒數、使用滑桿，或快速選擇 30／60／120／180 秒。
- **開始倒數：** 開始前倒數 3、2、1；倒數不占用正式遊戲時間。
- **持續隨機刷新：** 隨機維持最多 3 隻地鼠；每隻地鼠各自消失，不需等待整批結束。
- **雙重加速：** 遊戲後期地鼠刷新間隔變短，停留時間也縮短。
- **固定得分：** 點擊地鼠本體成功得 10 分；點空洞或漏打不扣分；同一隻只能計分一次。
- **擊中回饋：** 地鼠被擊中時播放動畫及 `+10` 提示。
- **內建音效：** 由 Web Audio API 產生倒數、開始、擊中、結束等提示音；可開啟／關閉。
- **暫停與繼續：** 暫停時計時與地鼠動畫同步停止。
- **重新開始保護：** 遊戲中重新開始前須確認，以免誤觸清除本局進度。
- **最高分紀錄：** 以遊戲秒數分開儲存，例如 30 秒與 60 秒各有獨立紀錄。
- **清除最高分：** 可在設定畫面一次清除全部紀錄，執行前需再次確認。
- **簡潔結算畫面：** 顯示本次分數、目前時間的最高分，以及再玩一次／返回設定。

## 遊戲規則

| 項目 | 規則 |
| --- | --- |
| 操作 | 使用滑鼠點擊地鼠本體 |
| 遊戲時間 | 10～180 秒，可自訂整數秒數 |
| 預設時間 | 30 秒 |
| 得分 | 每成功擊中一隻 +10 分 |
| 漏打、點空洞 | 不扣分 |
| 同時存在的地鼠 | 最多 3 隻；刷新時隨機選擇數量與位置 |
| 重複擊中 | 同一隻地鼠只能得分一次 |
| 難度 | 隨已經過的遊戲時間漸進加速 |
| 結束條件 | 倒數計時歸零 |

> 刷新是持續進行的，地鼠出現、縮回與被打中的時間不同，畫面可能短暫少於 1 隻地鼠；但不會超過 3 隻。

## 遊戲操作

### 開始前

- 調整遊戲秒數，並可查看**該秒數**對應的最高分。
- 使用畫面上的音效開關切換聲音。
- 如需重設所有最高分，可按「清除全部最高分紀錄」並確認。

### 遊戲中

- **暫停／繼續：** 控制計時、地鼠活動與動畫。
- **重新開始：** 顯示確認視窗；確定後清除本局進度並重新倒數 3、2、1；取消則維持原狀。
- **切換瀏覽器分頁：** 遊戲進行中會自動暫停，避免切換分頁後時間繼續流失。

### 遊戲結束

- **再玩一次：** 沿用本次遊戲時間，重新倒數後開新局。
- **返回時間設定：** 回到設定畫面，可變更遊戲秒數。
- 尚未完成就重新開始的局數不會更新最高分。

## 最高分與資料儲存

- 使用瀏覽器的 `localStorage` 保存最高分，依**實際設定秒數**分開記錄。
- 一局正常結束、且分數高於該時間原紀錄時，自動更新最高分並顯示「新紀錄」。
- 音效開關偏好也會嘗試存入 `localStorage`。
- 最高分只保存在使用中的瀏覽器／本機環境，不會上傳，也不會在不同瀏覽器之間同步。
- 直接以 `file://` 開啟時，不同瀏覽器對本機儲存的政策可能不同。若儲存受限制，遊戲仍可遊玩，但最高分可能只在該次頁面開啟期間有效；畫面會顯示提醒。
- 清除瀏覽器網站資料或使用不同的檔案位置／瀏覽器環境，也可能影響紀錄的保留。

## 技術說明

| 項目 | 說明 |
| --- | --- |
| 語言 | HTML、CSS、原生 JavaScript |
| 地鼠與圖示 | 內嵌 SVG；洞口與動畫主要由 CSS 呈現 |
| 音效 | 瀏覽器原生 Web Audio API |
| 計時與動畫 | `requestAnimationFrame` 配合遊戲狀態管理 |
| 資料儲存 | `localStorage`（失敗時以記憶體資料維持當次遊戲） |
| 外部依賴 | 無 |
| 網路需求 | 無，可離線使用 |
| 建議環境 | 桌面版現代瀏覽器 |
